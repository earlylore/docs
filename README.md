# EarlyLore

[EarlyLore](https://earlylore.com) is a product-validation, micro-SaaS market-research, and competitive-intelligence product. It is used to check a software idea against live products, pricing, traffic evidence, and competitor changes, and to bring that evidence into a coding agent through the hosted MCP server.

Public pages were reviewed for this file on **2026-11-10**. That date is a documentation sync. It is not a product release. The public changelog's newest dated entry at review time was **2026-11-08**. The website does not label an official launch date, so this repository does not add one.

![EarlyLore mark](https://earlylore.com/earlylore-mark.png)

## What the public product covers

The authoritative short index is [earlylore.com/llms.txt](https://earlylore.com/llms.txt). On 2026-11-10 it described the product as covering live software and AI products, indie creators, and software niches, plus computed first-screen styles (Design DNA). Read the live index before quoting a count. This repository does not freeze catalog, revenue, or Design DNA totals, because public pages disagree:

| Topic | What public pages currently print | Where to quote |
|---|---|---|
| Catalog size | `/llms.txt` says 440,000+. The homepage also shows a live exact counter. | The page you used, with the date you read it |
| Creators and niches | `/llms.txt` says 90,000+ indie creators and 249 niches | [/llms.txt](https://earlylore.com/llms.txt) |
| Design DNA | 9,700+ on `/llms.txt`, `/skill.md`, `/blog`, and the changelog introduction; 40,900+ on `/mcp` and the pricing page's IDE section | The page you used |
| Evaluation pipeline | 4-lane on the 2026-11-08 changelog entry and the live `/mcp` tool text; 6-lane on the 2026-11-06 changelog entry | [/changelog](https://earlylore.com/changelog) and [/mcp](https://earlylore.com/mcp) |
| Revenue coverage | Different pages use different populations (verified revenue, payment feeds, and dated founder disclosures) | The page that defines the population |

Traffic figures are provider estimates and need an observation month. Revenue is cited only when it is payment-verified or publicly disclosed with a source and date. A missing revenue figure means undisclosed.

## Plans

On 2026-11-10, [/pricing](https://earlylore.com/pricing) listed a free signed-in plan, pay-as-you-go evaluation packs at $1.9, $4.9, and $9.9, Pro at $129/year or $45/quarter, and Max at $249/year or $79/quarter.
