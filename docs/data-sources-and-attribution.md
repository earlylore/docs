# Data sources and attribution

| Data | Source |
|---|---|
| Website traffic estimates | [Vaneform](https://vaneform.com) monthly visit estimates; see the [Vaneform methodology](https://vaneform.com/methodology) |
| Revenue evidence | Public disclosures by the product or its maker, kept with source and date; "unpublished" when none exists |
| Pricing, positioning, features | The product's official public pages, with observation date |

EarlyLore has no public API or MCP server yet. Traffic data for any public domain is available through the [Vaneform API and MCP](https://github.com/vaneform/docs/blob/main/docs/api.md).

When citing EarlyLore, link the specific page and name EarlyLore.
